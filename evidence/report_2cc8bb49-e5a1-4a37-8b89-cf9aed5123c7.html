问题 D01；任务 2cc8bb49-e5a1-4a37-8b89-cf9aed5123c7

原始问题

比较 2018 年 Q1、Q2 的 GMV 和变化率（百分数）。先排除取消及不可用订单，再分析变化；不要把统计相关写成确定原因。

回答

2018 年 Q1 GMV 为 2,764,402.78（巴西雷亚尔），Q2 为 2,849,730.26，环比变化 +3.09%。口径：GMV = order_items.price 之和（不含运费），已排除 canceled 与 unavailable 订单，按订单购买时间分期。Q2 相对 Q1 小幅上升，但本查询仅呈现金额与变化率，未做归因分析，因此不能据此断定增长的具体原因（如需求、品类结构或促销等），相关因素需另行验证。

WITH q AS (SELECT CASE WHEN o.order_purchase_timestamp >= '2018-01-01' AND o.order_purchase_timestamp < '2018-04-01' THEN 'Q1' WHEN o.order_purchase_timestamp >= '2018-04-01' AND o.order_purchase_timestamp < '2018-07-01' THEN 'Q2' END AS quarter, SUM(i.price) AS gmv FROM orders AS o JOIN order_items AS i USING (order_id) WHERE NOT o.order_status IN ('canceled', 'unavailable') AND o.order_purchase_timestamp >= '2018-01-01' AND o.order_purchase_timestamp < '2018-07-01' GROUP BY 1) SELECT MAX(gmv) FILTER(WHERE quarter = 'Q1') AS q1_gmv, MAX(gmv) FILTER(WHERE quarter = 'Q2') AS q2_gmv, ROUND(100.0 * (MAX(gmv) FILTER(WHERE quarter = 'Q2') - MAX(gmv) FILTER(WHERE quarter = 'Q1')) / NULLIF(MAX(gmv) FILTER(WHERE quarter = 'Q1'), 0), 2) AS change_pct FROM q LIMIT 1000
